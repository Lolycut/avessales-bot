# 🧬 AvesSales — Telegram-бот расписания Биологического факультета БГУ

Асинхронный Telegram-бот для студентов и преподавателей биологического факультета БГУ (`bio.bsu.by`). Бот автоматически синхронизирует расписание с официальным сайтом факультета, поддерживает запросы на естественном языке (NLP/Fuzzy search), выводит расписание в виде форматированных таблиц, рассылает утренние уведомления и предоставляет панель администратора.

## ✨ Ключевые возможности

- 🎓 **Простая регистрация:** Пошаговый выбор курса (1–4), группы, подгруппы (1, 2 или вся группа) и кастомного обращения (никнейма).
- 📊 **Rich UI / Табличный вывод:** Генерация расписания с помощью встроенных таблиц и блоков сообщений.
- ⚡ **«Какая пара сейчас?»:** Моментальное определение текущей или следующей пары с подсказкой аудитории, типа занятия и преподавателя.
- ⚠️ **Детекция выездных пар:** Автоматическая пометка `⚠️ ВЫЕЗД!`, если пара проходит вне главного корпуса (не на ул. Курчатова, 10).
- 🔍 **Умный парсер запросов (NLP & Fuzzy Match):**
  - Распознавание опечаток и падежей: *«что во втрник»*, *«какая третья пара завтра»*, *«расписание на след неделю»*.
  - Быстрый просмотр расписания любой другой группы: *«1-41 на завтра»*, *«расписание 2-42 на пятницу»*.
  - Поиск преподавателя по фамилии: *«Где Рудакевич?»*, *«Кукулянская»*, *«пары Гричик»*.
- 🔔 **Утренние уведомления:** Автоматическая отправка расписания на день каждое утро в **07:45** (по часовому поясу Минска).
- 🗓 **Интерактивная неделя:** Просмотр расписания на всю неделю с кнопками переключения назад/вперед (`◀️ Пред.` / `След. ▶️`).
- 👑 **Админ-панель:** Статистика пользователей, просмотр логов, принудительная синхронизация API и техническая рассылка с защитой от спам-блокировок.
- 🌐 **Встроенный Healthcheck-сервер:** Сервер на `aiohttp` для предотвращения засыпания контейнеров (Render рекомендуется).

## 🛠 Стек технологий

- **Язык:** Python 3.10+
- **Фреймворк бота:** [aiogram 3.x](https://docs.aiogram.dev/) (полностью асинхронный)
- **База данных:** PostgreSQL
- **ORM / Драйвер:** [SQLAlchemy 2.0](https://www.sqlalchemy.org/) (AsyncIO) + [asyncpg](https://github.com/MagicStack/asyncpg)
- **HTTP-клиент:** [httpx](https://www.python-httpx.org/) (HTTP/1.1 с пулом соединений)
- **Веб-сервер заглушка:** [aiohttp](https://docs.aiohttp.org/)
- **Работа со временем:** `zoneinfo` (Europe/Minsk) + `tzdata`

## Быстрый старт и установка

### Требования
- Python `3.10` или выше
- PostgreSQL `14+`
- Установленный `git`

### Пошаговая установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/bio-schedule-bot.git
   cd bio-schedule-bot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   # Linux / macOS
   python3 -m venv venv
   source venv/bin/activate

   # Windows
   python -m venv venv
   venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Создайте базу данных в PostgreSQL:**
   ```sql
   CREATE DATABASE bio_schedule_db;
   ```

5. **Создайте и настройте `.env` файл:**
   ```bash
   cp .env.example .env
   ```
   Откройте `.env` в текстовом редакторе и укажите ваш `BOT_TOKEN`, `ADMIN_IDS` и реквизиты PostgreSQL.

6. **Запустите бота:**
   ```bash
   python main.py
   ```
   *При первом запуске бот автоматически создаст все таблицы в БД и выполнит полную первичную синхронизацию расписания с сайта факультета.*

## 💬 Примеры использования и запросов

### Поиск на естественном языке
Бот распознает свободные текстовые запросы:
- `что сегодня` / `пары завтра` / `что в четверг?`
- `какая 2 пара во вторник?`
- `3 пара завтра`
- `расписание на неделю` / `следующая неделя`

### Поиск чужих групп и преподавателей
- **Формат чужой группы:** `КУРС-ГРУППА`
  - `1-41 на завтра` — расписание 41 группы 1 курса на завтра
  - `3-41 в среду` — расписание 41 группы 3 курса на среду
  - `какая 1 пара у 2-42 в пт` — первая пара у 42 группы 2 курса в пятницу
- **Поиск преподавателей:**
  - `/teachers` или `/prep` — список доступных преподавателей в базе
  - `Кукулянская` / `Где Рудакевич?` / `пары Гричик` — карточка преподавателя со всеми его парами и группами на текущую неделю

### Команды администратора
Доступны только пользователям, чей ID указан в `ADMIN_IDS`:

| Команда | Описание |
| :--- | :--- |
| `/admin` или `/ahelp` | Справка по командам администратора |
| `/stats` | Количество пользователей, групп, сохраненных пар и активных подписок |
| `/sync` | Принудительная синхронизация расписания (1–4 курсы на 3 недели вперед) |
| `/tech <текст>` | Рассылка важного сообщения всем зарегистрированным пользователям |
| `/logs` | Выгрузка текущего файла логов `bot.log` документом в чат |

# 🚀 Пошаговый гайд: Бесплатный запуск бота 24/7

### 🗺 План действий:
1. Подготовить Telegram-бота и свой ID.
2. Создать облачную базу данных в **Supabase**.
3. Загрузить код на **GitHub**.
4. Запустить веб-сервис на **Render**.
5. Настроить пинг через **UptimeRobot** (чтобы бот никогда не «засыпал»).

---

## Шаг 1. Получаем токен бота и свой Telegram ID

1. **Создаем бота:**
   - Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
   - Отправьте команду `/newbot`, придумайте имя и юзернейм (должен заканчиваться на `_bot`).
   - Скопируйте выданный **HTTP API Token** (вида `1234567890:ABCdefGHI...`).
2. **Узнаем свой Telegram ID:**
   - Откройте бота [@userinfobot](https://t.me/userinfobot) или [@GetMyID_Bot](https://t.me/GetMyID_Bot).
   - Скопируйте цифры вашего `Id` (например: `582910492`).

---

## Шаг 2. Создаем бесплатную базу данных в Supabase

[Supabase](https://supabase.com) — это сервис, предоставляющий бесплатную базу данных PostgreSQL.

1. Зайдите на [supabase.com](https://supabase.com) и нажмите **«Sign in»** (удобно войти через GitHub).
2. Нажмите зеленую кнопку **«New project»**.
3. Заполните поля:
   - **Name:** любое имя (например, `bio-bot-db`).
   - **Database Password:** придумайте надежный пароль и **обязательно сохраните его** в блокнот.
   - **Region:** выберите ближайший к вам (например, `Central EU (Frankfurt)`).
   - Нажмите **«Create new project»** и подождите 1–2 минуты, пока база инициализируется.
4. **Получаем реквизиты для подключения:**
   - В левом меню в самом низу нажмите на иконку шестеренки ⚙️ (**Project Settings**).
   - Перейдите в раздел **«Database»**.
   - Пролистайте вниз до блока **«Connection parameters»** (или вкладки **Connection string** ➔ **URI / Parameters**):
     - **Host:** скопируйте хост (например: `db.xxxxxxxxxxxx.supabase.co` или адрес пулера `aws-0-eu-central-1.pooler.supabase.com`).
     - **Port:** `5432` (или `6543` при использовании пулера).
     - **Database name:** `postgres`.
     - **User:** `postgres` (или `postgres.xxxxxxx`, если через пулер).
     - **Password:** пароль, который вы задали в п. 3.

> 💡 **Про IPv4 и подключение:**  
> Если хостинг не поддерживает чистый IPv6, на этой же странице настроек базы в Supabase в блоке **Connection Pooling** переключите режим на **Session** (порт `5432`) или **Transaction** (порт `6543`) — это обеспечит подключение по стандартному IPv4.

## Шаг 3. Загружаем код бота на GitHub

1. Зайдите на [github.com](https://github.com) и создайте новый **публичный или приватный репозиторий** (например, `bio-schedule-bot`).
2. Загрузите в него все файлы вашего проекта (структура папок `handlers/`, `services/`, `main.py`, `config.py`, `models.py`, `database.py`, `keyboards.py`, `requirements.txt`).
3. Убедитесь, что в корне репозитория лежит файл **`Dockerfile`** (файл `.env` загружать на GitHub **не нужно** ради безопасности):

```dockerfile
FROM python:3.11-slim

WORKDIR /app
ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1

RUN apt-get update && apt-get install -y --no-install-recommends gcc libpq-dev && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 7860
CMD ["python", "main.py"]
```

## Шаг 4. Разворачиваем бота на Render

[Render.com](https://render.com) бесплатно запускает веб-сервисы с поддержкой Docker.

1. Зайдите на [render.com](https://render.com) и авторизуйтесь через **GitHub**.
2. В панели управления нажмите кнопку **«New +»** в правом верхнем углу и выберите **«Web Service»**.
3. Выберите **«Build and deploy from a Git repository»** и нажмите **Next**.
4. Найдите в списке ваш репозиторий с ботом и нажмите **«Connect»**.
5. Заполните настройки проекта:
   - **Name:** любое понятное имя (например, `bio-bsu-bot`).
   - **Region:** Frankfurt (желательно тот же регион, что и у Supabase).
   - **Runtime:** `Docker` (Render сам определит `Dockerfile`).
   - **Instance Type:** `Free` ($0/month).
6. **Настройка Health Check (проверка работоспособности):**
   - Пролистайте вниз и нажмите на **«Advanced»**.
   - Найдите поле **«Health Check Path»** и впишите туда: `/health` (или `/`).
7. **Добавляем переменные окружения:**
   - В блоке **«Environment Variables»** добавьте параметры (нажимая *Add Environment Variable*):

| Key (Ключ) | Value (Значение) |
| :--- | :--- |
| `BOT_TOKEN` | Ваш токен от @BotFather |
| `ADMIN_IDS` | Ваш числовой Telegram ID |
| `DB_HOST` | Хост из Supabase (например, `db.xxx.supabase.co`) |
| `DB_PORT` | `5432` |
| `DB_NAME` | `postgres` |
| `DB_USER` | `postgres` (или пользователь из параметров Supabase) |
| `DB_PASSWORD` | Ваш пароль от базы Supabase |

8. Нажмите внизу синюю кнопку **«Create Web Service»**.
9. **Готово!** Render начнет сборку Docker-образа.
   - В вкладке **Logs** вы увидите, как создаются таблицы БД и подтягивается расписание с сайта `bio.bsu.by`.
   - Через 1–2 минуты статус изменится на зеленый **«Live»**.
   - Скопируйте ссылку на ваш сервис сверху слева под названием (вида `https://bio-bsu-bot.onrender.com`).

## Шаг 5. Настраиваем UptimeRobot (чтобы бот не спал)

На бесплатном тарифе Render сервис засыпает через 15 минут, если на него не приходят входящие запросы. Сервис [UptimeRobot](https://uptimerobot.com) будет пинговать бота каждые 5 минут, удерживая его активным 24/7.

1. Зайдите на [uptimerobot.com](https://uptimerobot.com) и зарегистрируйте бесплатный аккаунт.
2. В личном кабинете нажмите кнопку **«+ Add New Monitor»**.
3. Заполните поля:
   - **Monitor Type:** выберите `HTTP(s)`.
   - **Friendly Name:** `Bio Bot Health`.
   - **URL (or IP):** вставьте ссылку вашего сервиса с Render, добавив в конец `/health`  
     *(Пример: `https://bio-bsu-bot.onrender.com/health`)*.
   - **Monitoring Interval:** `every 5 minutes`.
4. Нажмите внизу **«Create Monitor»**.
